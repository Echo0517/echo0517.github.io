DITOCR: A Decoder-Only Transformer for Industrial Optical Character Recognition

AIEA, 2025

Shengyuan Wang, Wenjie Cai (co-first author), Rihui Xia, Xingbo Dong, Zhe Jin

Anhui University

Paper

Overview

DITOCR is a decoder-only framework for industrial optical character recognition. A convolutional feature extractor and patch embeddings feed a GPT-2-based decoder, which generates character sequences autoregressively. Character-level attention supports robust recognition in industrial scenes. Wenjie Cai contributed as a co-first author to the framework design, experiments, and paper writing.

Highlights

  • Use convolutional features with a decoder-only transformer.
  • Generate industrial text sequences autoregressively.
  • Support robust recognition with character-level attention.
